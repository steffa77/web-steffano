# El Mundo del Fútbol

## Descripción
- El fútbol es uno de los deportes más populares del mundo.
- Hubo jugadores que se convirtieron en leyendas.
- También hay equipos destacados como el Real Madrid, Barcelona, Milan e Inter.
## Objetivo 
- Mostrar equipos y jugadores que han marcado época en el Fútbol.
## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
## Cómo visualizar el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta web-steffano en Visual Studio Code.
3. Abrir el archivo index.html en el navegador.
